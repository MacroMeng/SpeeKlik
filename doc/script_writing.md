# 如何编写SpeeKlik脚本

> 本条目将指导你编写SpeeKlik脚本的操作。你可以将编写好的脚本导入到SpeeKlik中运行，或是将它发送给别人。

> [警告]!运行脚本前应该确保这个脚本没有恶意。我们不承担有不仔细阅读此条目引发的所有责任。!

## 主要外观

SpeeKlik脚本看起来如下所示：

```
@|default_delay=0.05|failsafe=True|
K|0|delay=0|
M|L|
M|L|
```

## 预定义

预定义是以`@`开头的行。这类行的格式如下：（使用`regex`）

```
@|((\S)+=(\S+)|)+
```

使用人类友好文字，表达如下：

```
@|多个(变量名(字符)=变量值)以|分隔
```

参考“主要外观”中的例子，`default_delay`与`failsafe`分别是“变量名”，而`0.05`与`True`分别是变量的值。

在SpeeKlik中，可用的变量值有：

- `default_delay`指定了默认的间隔。此选项会在命令没有指定`delay`时使用。若没有指定，命令也没有指定`delay`，则SpeeKlik会报错。
- `safe_delay`指定了安全间隔。这个选项会覆盖`pyautogui.PAUSE`，详细信息可以在[pyautogui的文档](https://pyautogui.readthedocs.io/en/latest/index.html?highlight=failsafe#fail-safes)中找到。
- `failsafe`指定`pyautogui.FAILSAFE`的值。详细信息同样参考上面的链接。

## 命令

命令是如如下定义的行：

```
[KM]|(\S+)
```

开头的字母（`K`/`M`）决定了这是鼠标命令还是键盘命令。具体参考下述文档。

### 鼠标命令

鼠标命令如下定义：

```
M|[LMR]|(\(\d+, \d+\)|)?(delay=\d+\.?\d+?)?
```

这表示一个最多的鼠标命令行如下所示：

```
M|R|(1,1)|delay=0.1
```

以下是可用的参数：

- 第二项，即LMR中的一个：分别表示左、中、右键。
- 第三项（可选），即(Num,Num)：点击的坐标。未指定则默认为目前的鼠标坐标。
- 第四项（可选，因此也可为第三项）：指定与上次点击（无论是鼠标或是键盘）相隔的时刻。此设置在键盘命令中同样有用。

### 键盘命令

键盘命令如下定义：

```
K|(\S)+|(delay=\d+\.?\d+?)?
```

典型的键盘命令则如下所示：

```
K|O|delay=0.5
```

这代表与上次命令执行间隔0.5秒后，模拟按下O键。

以下是可用的参数：

- 第二项：任意一个字母。若长度不唯一，则尝试解析为Unicode表达（如|可以使用U+007C替换。此种表达必须以U+开头，最好使用全大写的16进制字符）；若不能解析则会发生错误。
- 第三项（可选）：delay项，参见鼠标命令-参数-第四项（可选）。
